[An introduction to Power BI Certificate from Data Camp was awarded on 9/30/2026 as part of my BNAN 430 coursework.
](https://public.tableau.com/views/PowerBIDataCampBNAN430/PowerBIStory?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)One thing Power BI does automatically that I did by hand in Excel is connect related tables. In Excel, I used VLOOKUP or XLOOKUP to create new columns, but in Power BI, the tables I loaded were linked through relationships it detected on matching columns. Next time, I would choose Power BI for this task because the relationships update automatically when the data refreshes, which avoids broken formulas and saves me from pasting static values into my tables. For a quick one-time analysis with a small dataset I might still use Excel, but for anything larger or more advanced, Power BI is the better fit.

[An introduction to DAX Certificate from Data Camp was awarded on 10/7/2026 as part of my BNAN 430 coursework.
](https://public.tableau.com/app/profile/noah.slepian/viz/PowerBIDataCampBNAN430/PowerBIStory?publish=yes)In Excel, I calculated net contribution by subtracting cost to serve from profit for each customer, and I put it in the last column of my Account Summary table. Cost to serve was a flat fee based on account tier. In Power BI, I would build net contribution as a measure, Net Contributions = SUM(Profit) - SUM(Cost to Serve), because it has to recalculate for whatever the reader filters on, like region, category, or dates. A calculated column would lock in one value per row at refresh, so it couldn't answer a new question in a meeting. With the measure in the model, Anita can slice net contribution by whatever she's curious about in the moment, and Marcus can compare tiers to see where we're losing money without waiting on me for a new workbook.

In Flex 4, my Tableau scatter plotted average discount against profit by subcategory, showing Tables and Bookcases losing money at high discount rates. In Power BI, I would add red conditional formatting on negative profit and a region slicer, so Marcus can judge whether discounting is the lever to pull and Anita can check any region mid-meeting. Second, my Excel Account Summary had a Net Contributions column: profit minus a flat tier fee of $60, $400, or $1,200. It was a fixed column, so every new cut by region or month meant rebuilding the table. In Power BI, I would write it once as a measure, so it recalculates for whatever Anita filters without charging the fee per order.
Excel is still right for quick one-off checks on small data. Tableau is right for designing one polished view for one decision. Power BI is right when a report refreshes and other people depend on it. My gap is that I’ve never published to the Power BI Service, so I don’t know where Southwest wants finished work to live. I would ask you or IT for the workspace and naming conventions, publish a practice report to a test space first, and get a review before anyone relies on it.
